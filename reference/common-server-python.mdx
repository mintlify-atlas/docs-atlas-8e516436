CommonServerPython is the shared runtime library that the Cortex XSOAR server automatically injects into every integration and script before execution. You do not need to bundle or install it — simply import its exports at the top of any integration or script file. The module lives in the content repository at `Packs/Base/Scripts/CommonServerPython/CommonServerPython.py` and is updated with each platform release.

```python
from CommonServerPython import *
```

The wildcard import is the standard convention because CommonServerPython is designed as a single flat namespace. All classes, functions, constants, and the `demisto` mock object are made available to your code immediately.

| `EntryType.NOTE` | `1` | Standard note entry (default for `CommandResults`) |
| `EntryType.FILE` | `3` | File attachment entry |

| `EntryType.IMAGE` | `7` | Image entry |

## Utility Functions

### is_debug_mode()

Returns `True` when the command was invoked with the `debug-mode=true` option in the War Room.

```python
if is_debug_mode():
    demisto.debug("Verbose diagnostic output here")
```

### auto_detect_indicator_type(indicator_value)

Infers the indicator type from the value string. Requires the `tldextract` library (available in the `demisto/jmespath` Docker image and others).

```python
ioc_type = auto_detect_indicator_type("8.8.8.8")
# returns FeedIndicatorType.IP
```

### handle_proxy(proxy_param_name='proxy', checkbox_default_value=False, handle_insecure=True, insecure_param_name=None)

Reads the `proxy` integration parameter and configures environment variables accordingly. Also handles the `insecure` / `unsecure` parameter when `handle_insecure=True`. Returns a `proxies` dict suitable for passing to `requests`.

```python
proxies = handle_proxy()
```

### skip_proxy()

Deletes `HTTP_PROXY`, `HTTPS_PROXY`, `http_proxy`, and `https_proxy` environment variables so that HTTP requests bypass the system proxy.

### skip_cert_verification()

Deletes `REQUESTS_CA_BUNDLE` and `CURL_CA_BUNDLE` environment variables, causing `requests` to skip SSL certificate validation.

### tableToMarkdown(name, t, headers=None, headerTransform=None, removeNull=False, metadata=None, url_keys=None, date_fields=None)

Converts a list of dicts (or a single dict) to a Markdown table string for display in the War Room.

```python
md = tableToMarkdown("Incidents", incidents, headers=["id", "severity", "status"])
```

## The `demisto` Module Interface

The `demisto` object is the bridge between your integration code and the XSOAR platform. It is automatically available after `from CommonServerPython import *`.

| Method | Description |
|---|---|
| `demisto.command()` | Returns the name of the currently executing command as a string, e.g. `'ip'`. |
| `demisto.args()` | Returns a `dict` of the command arguments passed by the user. |
| `demisto.params()` | Returns a `dict` of the integration instance configuration parameters. |
| `demisto.incidents(list)` | Creates incidents in XSOAR. Used in `fetch-incidents` to push fetched events. |
| `demisto.getLastRun()` | Returns the persistent state `dict` saved by the last run. |
| `demisto.setLastRun(dict)` | Saves a `dict` as persistent state for the next scheduled run. |
| `demisto.debug(str)` | Writes a DEBUG-level log message. Only visible when debug mode is enabled. |
| `demisto.info(str)` | Writes an INFO-level log message to the integration log. |
| `demisto.error(str)` | Writes an ERROR-level log message to the integration log. |
| `demisto.executeCommand(name, args)` | Calls another integration command or automation script by name. |
| `demisto.context()` | Returns the current incident's context data as a `dict`. |
| `demisto.results(entry)` | Low-level method to push a War Room entry dict. Prefer `return_results()` instead. |

### Usage pattern

```python
from CommonServerPython import *

def main():
    command = demisto.command()
    args = demisto.args()
    params = demisto.params()

    try:
        if command == 'test-module':
            return_results('ok')
        elif command == 'ip':
            results = ip_command(args.get('ip'))
            return_results(results)
    except DemistoException as e:
        return_error(f'Failed to execute {command}. Error: {e}')

if __name__ in ('__main__', '__builtin__', 'builtins'):
    main()
```

The DBotScore system is the XSOAR standard for communicating indicator reputation. Every enrichment integration produces a `Common.DBotScore` object attached to an indicator (`Common.IP`, `Common.URL`, `Common.Domain`, etc.) which the platform renders as a colored score badge in the War Room and in the indicator's summary panel. All three classes — `DBotScoreType`, `DBotScoreReliability`, and `Common.DBotScore` — are available after `from CommonServerPython import *`.

---

## Numeric Score Values

The four score levels are defined as integer constants on `Common.DBotScore`:

| Constant | Value | Meaning |
|---|---|---|
| `Common.DBotScore.NONE` | `0` | Unknown — no reputation data available |
| `Common.DBotScore.GOOD` | `1` | Good — indicator is known to be benign |
| `Common.DBotScore.SUSPICIOUS` | `2` | Suspicious — indicator shows signs of malicious activity |
| `Common.DBotScore.BAD` | `3` | Bad — indicator is confirmed malicious |

---

## `class DBotScoreType`

String constants that identify the category of an indicator. Pass one of these to `Common.DBotScore(indicator_type=...)`.

```python
class DBotScoreType(object):
    IP = 'ip'
    FILE = 'file'
    DOMAIN = 'domain'
    URL = 'url'
    CVE = 'cve'
    ACCOUNT = 'account'
    CIDR = 'cidr'
    DOMAINGLOB = 'domainglob'
    CERTIFICATE = 'certificate'
    CRYPTOCURRENCY = 'cryptocurrency'
    EMAIL = 'email'
    ATTACKPATTERN = 'attackpattern'
    CUSTOM = 'custom'
```

| Constant | Value | Use Case |
|---|---|---|
| `DBotScoreType.IP` | `'ip'` | IPv4 or IPv6 address reputation |
| `DBotScoreType.FILE` | `'file'` | File hash (MD5, SHA1, SHA256, SHA512) reputation |
| `DBotScoreType.DOMAIN` | `'domain'` | Domain name reputation |
| `DBotScoreType.URL` | `'url'` | Full URL reputation |
| `DBotScoreType.CVE` | `'cve'` | CVE vulnerability identifier |
| `DBotScoreType.ACCOUNT` | `'account'` | User account reputation |
| `DBotScoreType.CIDR` | `'cidr'` | IP CIDR range |
| `DBotScoreType.DOMAINGLOB` | `'domainglob'` | Wildcard domain pattern (e.g. `*.evil.com`) |
| `DBotScoreType.CERTIFICATE` | `'certificate'` | X.509 certificate |
| `DBotScoreType.CRYPTOCURRENCY` | `'cryptocurrency'` | Cryptocurrency wallet address |
| `DBotScoreType.EMAIL` | `'email'` | Email address reputation |
| `DBotScoreType.ATTACKPATTERN` | `'attackpattern'` | MITRE ATT&CK technique |
| `DBotScoreType.CUSTOM` | `'custom'` | Custom indicator type |

### Validation

```python
DBotScoreType.is_valid_type('ip')     # True
DBotScoreType.is_valid_type('foobar') # False
```

## `class DBotScoreReliability`

Reliability grades that communicate the trustworthiness of the source that produced a score. Pass one of these string constants to `Common.DBotScore(reliability=...)`.

```python
class DBotScoreReliability(object):
    A_PLUS_PLUS = 'A++ - Reputation script'
    A_PLUS     = 'A+ - 3rd party enrichment'
    A          = 'A - Completely reliable'
    B          = 'B - Usually reliable'
    C          = 'C - Fairly reliable'
    D          = 'D - Not usually reliable'
    E          = 'E - Unreliable'
    F          = 'F - Reliability cannot be judged'
```

| Constant | String Value | Intended Use |
|---|---|---|
| `DBotScoreReliability.A_PLUS_PLUS` | `'A++ - Reputation script'` | Internal reputation scripts with full context |
| `DBotScoreReliability.A_PLUS` | `'A+ - 3rd party enrichment'` | Premium commercial threat intel feeds |
| `DBotScoreReliability.A` | `'A - Completely reliable'` | Highly trusted sources |
| `DBotScoreReliability.B` | `'B - Usually reliable'` | Generally trustworthy sources |
| `DBotScoreReliability.C` | `'C - Fairly reliable'` | Community or open-source feeds |
| `DBotScoreReliability.D` | `'D - Not usually reliable'` | Sources that are occasionally unreliable |
| `DBotScoreReliability.E` | `'E - Unreliable'` | Sources with low confidence |
| `DBotScoreReliability.F` | `'F - Reliability cannot be judged'` | Unknown or untested sources |

## `Common.DBotScore`

The `Common.DBotScore` class is nested inside `Common` and represents a complete reputation verdict for a single indicator value.

### Constructor

```python
Common.DBotScore(
    indicator,
    indicator_type,
    integration_name='',
    score=None,
    malicious_description=None,
    reliability=None,
    message=None,
)
```

<ParamField path="indicator" type="str" required>
  The raw indicator value, for example `'8.8.8.8'`, `'evil.com'`, or a SHA256 hash string.
</ParamField>

<ParamField path="indicator_type" type="DBotScoreType" required>
  One of the `DBotScoreType` string constants, for example `DBotScoreType.IP`. Raises `TypeError` if not a valid type.
</ParamField>

<ParamField path="integration_name" type="str" default="''">
  The name of the integration or vendor providing the score. For integrations this is auto-detected from the calling context; for scripts it must be provided explicitly.
</ParamField>

<ParamField path="score" type="int" required>
  One of `Common.DBotScore.NONE` (0), `Common.DBotScore.GOOD` (1), `Common.DBotScore.SUSPICIOUS` (2), or `Common.DBotScore.BAD` (3). Raises `TypeError` if not a valid score value.
</ParamField>

<ParamField path="malicious_description" type="str">
  A human-readable explanation shown when `score` is `Common.DBotScore.BAD`. For example: `'Known C2 server associated with Lazarus Group'`.
</ParamField>

<ParamField path="reliability" type="DBotScoreReliability">
  The reliability grade of the source. Must be a valid `DBotScoreReliability` constant. Raises `TypeError` if set to an invalid value.
</ParamField>

<ParamField path="message" type="str">
  An optional message about the API response, for example `'Not found'` when the vendor has no data on the indicator.
</ParamField>

### Context Standard

When `Common.DBotScore.to_context()` is called (via `CommandResults`), it writes to the following context paths:

| Context Key | Description |
|---|---|
| `DBotScore.Indicator` | The indicator value |
| `DBotScore.Type` | The indicator type string |
| `DBotScore.Vendor` | The integration name |
| `DBotScore.Score` | The integer score (0–3) |
| `DBotScore.Reliability` | The reliability string (when set) |

## Complete Example: Scoring an IP Indicator

```python
from CommonServerPython import *

def ip_command(client, args):
    ip_value = args.get('ip', '')
    result = client.get_reputation(ip_value)

    # Determine score
    malicious = result.get('malicious', False)
    suspicious = result.get('suspicious', False)

    if malicious:
        score = Common.DBotScore.BAD
        malicious_description = result.get('reason', 'Flagged as malicious by vendor')
    elif suspicious:
        score = Common.DBotScore.SUSPICIOUS
        malicious_description = None
    else:
        score = Common.DBotScore.GOOD
        malicious_description = None

    # Build DBotScore
    dbot_score = Common.DBotScore(
        indicator=ip_value,
        indicator_type=DBotScoreType.IP,
        integration_name='MyThreatIntel',
        score=score,
        malicious_description=malicious_description,
        reliability=DBotScoreReliability.B,
    )

    # Build IP indicator
    ip_indicator = Common.IP(
        ip=ip_value,
        dbot_score=dbot_score,
        asn=result.get('asn'),
        geo_country=result.get('country'),
        organization_name=result.get('org'),
    )

    readable = tableToMarkdown(
        f'IP Reputation: {ip_value}',
        {
            'IP': ip_value,
            'Score': dbot_score.to_readable(),
            'ASN': result.get('asn'),
            'Country': result.get('country'),
        },
    )

    return CommandResults(
        outputs_prefix='MyThreatIntel.IP',
        outputs_key_field='Address',
        outputs={'Address': ip_value, **result},
        readable_output=readable,
        raw_response=result,
        indicator=ip_indicator,
    )
```

The `Common Scripts` Pack (`Packs/CommonScripts`) is the standard library of Cortex XSOAR automation. Authored and maintained by the Cortex XSOAR team and tagged as a `Core` pack, it ships pre-installed on every XSOAR deployment and is available across all supported marketplaces — `xsoar`, `marketplacev2`, `xpanse`, and `platform`. With over 295 scripts spanning data transformation, indicator utilities, incident management, file handling, and more, it is the first place to look before writing any custom automation.

<Tip>
  Before writing a custom script, search the Common Scripts Pack — many common data transformation and indicator operations are already implemented. Run `!GetEnabledInstances` or browse `Packs/CommonScripts/Scripts/` in the content repository to discover available scripts.
</Tip>

The pack's `pack_metadata.json` identifies it as version `1.22.58` (current as of the content repository HEAD), with a hard dependency on `DemistoRESTAPI` and optional dependencies on email integrations (Gmail, Microsoft Graph Mail, Mail Sender) for scripts that send notifications.

## Calling a Common Script from a Playbook

Any Common Script can be invoked as a `regular` task in a playbook. The `task.script` field contains the script name; `scriptarguments` passes inputs as named key-value pairs:

```yaml
"5":
  id: "5"
  taskid: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
  type: regular
  task:
    id: aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
    version: -1
    name: Encode value to Base64
    description: Run Base64EncodeV2 on the extracted file hash.
    script: Base64EncodeV2
    type: regular
    iscommand: false
    brand: ""
  nexttasks:
    '#none#':
      - "6"
  scriptarguments:
    input:
      simple: ${File.MD5}
  separatecontext: false
```

## Calling a Common Script from Another Script

Inside a Python script you can invoke any other script using `demisto.executeCommand()`:

```python
import demistomock as demisto
from CommonServerPython import *


def main():
    target_value = demisto.args().get("value", "")

    # Call ArrayToCSV to convert a list already in context to a string
    result = demisto.executeCommand("ArrayToCSV", {"value": target_value})

    if is_error(result):
        return_error(f"ArrayToCSV failed: {get_error(result)}")

    csv_string = result[0].get("Contents", "")
    return_results(
        CommandResults(
            outputs_prefix="MyScript",
            outputs={"CSVOutput": csv_string},
            readable_output=f"CSV Result: `{csv_string}`",
        )
    )


if __name__ in ("__main__", "__builtin__", "builtins"):
    main()
```

`demisto.executeCommand(script_name, args_dict)` returns a list of result entries. Use the `is_error()` and `get_error()` helpers from `CommonServerPython` to detect and surface failures.

## Script Categories

<Accordion title="Data Transformation">

These scripts reformat, encode, parse, or calculate values from raw data. They are the most commonly used category in playbook pipelines.

| Script | Type | Description |
|--------|------|-------------|
| `Base64Encode` | JavaScript | Encodes an input string to Base64 format. Writes the result to `Base64.encoded`. |
| `Base64EncodeV2` | Python 3 | Python reimplementation of `Base64Encode`. Accepts a single `input` argument and writes to `Base64.encoded`. Use this for new playbooks. |
| `ArrayToCSV` | Python 3 | Converts a simple array (list of strings) to a comma-separated string. Tagged as a `transformer`. |
| `CEFParser` | JavaScript | Parses a CEF (Common Event Format) log string into structured key-value fields suitable for context mapping. |
| `CalculateEntropy` | Python 3 | Computes Shannon entropy for a given string. Useful for detecting high-entropy (obfuscated or encoded) values in command lines or file names. Accepts `data` and `minimum_entropy` arguments; writes to `EntropyResult`. |
| `CalculateTimeDifference` | JavaScript | Calculates the difference between two timestamps in minutes. Writes `Time.Difference`, `Time.Start`, and `Time.End` to context. |
| `ConvertTableToHTML` | JavaScript | Renders a context table as an HTML string for embedding in email or layout widgets. |
| `ConvertXmlToJson` | JavaScript | Parses an XML string and converts it to a JSON-compatible dictionary. |
| `ConvertDateToUTC` | Python | Normalises a date string from a given timezone to UTC. |
| `DecodeMimeHeader` | Python | Decodes MIME-encoded email header values (e.g. RFC 2047 `=?utf-8?B?...?=` strings). |
| `FormatURL` | Python | Normalises and defangs or refangs URLs for consistent comparison and storage. |
| `JSONtoCSV` | Python | Converts a JSON array of objects to a CSV file entry. |
| `MapValues` | JavaScript | Maps input values to output values using a provided mapping table — useful for normalising vendor-specific status codes to standard values. |
| `MatchRegex` | JavaScript | Tests a string against a regular expression and returns match groups. |
| `PrettyPrint` | Python | Pretty-prints a JSON or Python object for human-readable war-room display. |
| `StringReplace` | JavaScript | Replaces all occurrences of a substring within a string. |
| `TextFromHTML` | Python | Strips HTML tags and returns the plain-text content of an HTML string. |
| `UnEscapeURLs` | JavaScript | Unescapes URL-encoded or safety-wrapped (e.g. ProofPoint, Mimecast) URLs to their original form. |

</Accordion>

| `AddEvidence` | JavaScript | Adds one or more war-room entries to the incident Evidence Board. Accepts entry IDs (defaults to `${lastCompletedTaskEntries}`), a description, timestamp, and tags. |
| `BreachConfirmationHTML` | Python 3 | Renders a dynamic HTML confirmation widget for breach acknowledgement flows in incident layouts. |
| `CloseInvestigationAsDuplicate` | Python | Closes the current incident as a duplicate and links it to a specified parent investigation. |
| `CopyNotesToIncident` | Python | Copies note entries from the current incident to a target incident by ID. |
| `FindSimilarIncidentsV2` | Python | Queries XSOAR for incidents that share indicator values or field text with the current incident, enabling deduplication and correlation. |
| `IncreaseIncidentSeverity` | JavaScript | Raises incident severity by one level (e.g. Low → Medium) if a condition is met. |
| `LinkIncidentsButton` | Python | Provides a one-click layout button to link two incidents together. |
| `SearchIncidentsV2` | Python | Executes an XSOAR incident query and returns matching incidents. |
| `SetGridField` | Python | Populates an XSOAR grid-type incident field with a list of records. |
| `GetDataCollectionLink` | Python | Generates a data-collection (questionnaire) link for an analyst or external stakeholder. |

</Accordion>

<Accordion title="Indicator Utilities">

These scripts work with security indicators — computing reputation scores, handling DBotScore entries, verifying indicator formats, and assessing CVE severity.

| Script | Type | Description |
|--------|------|-------------|
| `AddDBotScoreToContext` | Python 3 | Creates a `DBotScore` context entry for a custom indicator with explicit `indicator`, `indicatorType`, `score`, `vendor`, and `reliability` values. Uses `CommandResults` and `return_results()`. |
| `CVECVSSColor` | Python | Returns a CSS colour string (e.g. `red`, `orange`, `yellow`) corresponding to a CVSS score, used in incident layout widgets to provide at-a-glance severity colouring. |
| `CVSSCalculator` | Python 3 | Full CVSS 3.0 / 3.1 calculator. Accepts all base, temporal, and environmental metric arguments and writes `CVSS.BaseScore`, `CVSS.TemporalScore`, `CVSS.EnvironmentalScore`, `CVSS.VectorString`, and related sub-scores to context. |
| `GetIndicatorDBotScore` | Python | Retrieves the current DBotScore for an indicator from the XSOAR threat-intelligence store. |
| `IsMaliciousIndicatorFound` | JavaScript | Returns `yes` or `no` based on whether any indicator in context has a DBotScore ≥ 3 (malicious). |
| `IsIPInRanges` | JavaScript | Checks whether an IP address falls within any of a provided list of CIDR ranges. |
| `IsIPPrivate` | JavaScript | Returns `yes` if an IP address is in RFC 1918 or other private-use ranges. |
| `IsDomainInternal` | Python | Checks a domain against a configured list of internal domain suffixes. |
| `ExtractDomainAndFQDNFromUrlAndEmail` | Python | Parses URLs and email addresses to extract the domain and fully qualified domain name components. |
| `IndicatorMaliciousRatioCalculation` | Python | Computes the ratio of malicious to total detections for an indicator across all returned DBotScore entries. |
| `CreateIndicatorsFromSTIX` | Python | Parses a STIX 2.x bundle and creates XSOAR indicator objects for each STIX object found. |
| `FetchIndicatorsFromFile` | Python | Extracts indicators (IPs, domains, hashes, URLs) from an uploaded file and creates them in the XSOAR indicator store. |

</Accordion>
